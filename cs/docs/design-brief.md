# 反恐突袭 · 设计概念卡（Lean / Phase 1）

| 项 | 值 |
|---|---|
| 目录 / id | `cs/` · `cs` |
| 显示名 | 反恐突袭（对外文案不得出现任何第三方商标字样） |
| 形态 | 透视投影 Canvas 2D 软渲染、第一/第三人称可切换射击，敌人为本地 AI Bot，无联网 |

## 1. 设计支柱
1. **零依赖、单帧几十面**：画面 = 手写透视投影 + 画家算法绘制的轴对齐立方体（AABB）色块 + 公告板精灵；不引入 WebGL、贴图包、物理库。任何新机制若把逐帧可见面推过 ~80 即视为违背支柱。
2. **一键换镜，同景双读**：FPS/TPS 仅切换相机位置与玩家模型显隐，共用同一套场景、yaw/pitch、命中射线与全部数值；切镜是观察工具，不是强度开关。
3. **掩体即战术**：深度全部来自几何（墙体遮挡射线、绕侧取得视线、波间整备），不来自装备、数值成长或剧情。

## 2. MDA（压缩）
| 层 | 内容 |
|---|---|
| 机制 M | AABB 场景 + hitscan 即时射线（先判墙再判 Bot）；弹匣 8 发 / 换弹 1.4 s 计时；移速联动散布；3 波 Bot 生成与视线判定；Score = 100×击杀 + 10×命中弹 |
| 动态 D | 掩体后换弹、探头点射、绕侧取视线、静止精瞄、波间整备；TPS 读自身与掩体位置关系，FPS 读准星与射线的零歧义 |
| 美学 A | 3~5 分钟可复盘的短局；胜任感来自散布控制与掩体选择，自主性来自视角/路线自选；低多边形纯色块保证读图清晰。观感一律用可测量项（面数、色值、FOV）描述，禁止含糊观感词 |

## 3. 核心循环（动词优先）
`移动` → `侦察`（找出有视线的 Bot / 掩体缺口）→ `瞄准`（停下或 Shift 消散布）→ `射击`（按住连发，hitscan）→ `换弹`（空仓自动 / R 主动，1.4 s 窗口）→ `清场·推进`（本波 Bot 全灭，2.0 s 整备）→ `下一波`（数量与命中率递增）→ 第 3 波清场 = 通关。
每圈 10~25 s，3 波合计 3~5 min。

## 4. 胜负与波次
| 条件 | 规则 |
|---|---|
| 胜 | 第 3 波 Bot 全部歼灭 → 结算「任务完成」 |
| 负 | 玩家 HP ≤ 0 → 立即冻结输入与波次生成，结算「任务失败」 |
| 波推进 | 本波 Bot 数归零 → 2.0 s 整备（自动补满弹匣、回复 +20 HP 上限 100、不重置位置）→ 生成下一波 |
| 波次 | 3 波；Bot 数 3 / 4 / 5，命中率 0.35 / 0.45 / 0.55，其余数值不随波变化 |

**Bot 行为状态机（低开销）**：守点/巡逻 → 取得视线则停止移动并每 1.2 s 尝试开火一次（命中率判定）→ 失去视线连续 2.0 s 则重选巡逻点。无 A*、无导航网格。
**平衡校验**：弹匣 8 发可清 4 个 Bot；第 3 波 5 个 Bot（需 10 发）必然触发至少 1 次换弹，换弹成为真实战术窗口而非摆设。峰值承伤 ≈ 2 × (1/1.2) × 0.55 × 8 ≈ 7.3 点/s，100 HP ≈ 13.7 s 连续暴露 → 强制使用掩体但不至于秒杀。

## 8. 关键屏 UX（纯色块 / DOM 覆盖层，无贴图）
- **主菜单**：标题「反恐突袭」+ 一句话副标题；[开始任务] [操作说明]；最高分；视角预览指示（FPS/TPS）；跟随站点明暗主题。
- **核心 HUD**：中心准星（十字 4 段，间隙随散布实时变化，可视化精度）｜左下 HP 条 + 数字｜右下 `8 / ∞` + 换弹进度条｜顶中 `WAVE 1/3` + 剩余 Bot 数 + 波间倒计时｜顶右 `SCORE`｜角落 `FPS/TPS` 指示（V 切换时短暂高亮）｜受击屏幕边缘红闪 0.2 s｜击杀 `+100` 浮字。仅 6 个信息块，防认知过载。
- **暂停**：半透明遮罩 + [继续] [重新开始] [返回主菜单] + 操作映射速查；失焦自动进入。
- **结算**：胜/败标题、到达波次、击杀数、命中率、剩余 HP、用时、比分、最高分（新纪录标记）、[再来一局] [返回主菜单]。

## 9. 边缘情况（含处理规则）
1. **切镜瞬间受击/开火**：切镜仅改相机，不中断射击、换弹、受击结算；不提供无敌帧（防「切镜躲伤害」主导策略）。换弹中允许切镜，计时继续。
2. **空仓开火**：不发射、不消耗、不计空枪分；弹药数字闪红并自动触发换弹；换弹期间重复按左键 / R 不排队第二次计时。
3. **Bot 卡墙 / 波次无法结束**：圆 vs AABB 轴分离滑动禁入墙体；连续 2.0 s 无玩家视线则重选预设巡逻点；地图布局须保证每个巡逻点到玩家直线或单次绕行可达。
4. **失焦 / 切后台 / Pointer Lock 丢失**：自动暂停并冻结 dt；恢复须玩家主动点「继续」并重新锁鼠标，禁止用累计大 dt 补算。
5. **TPS 相机穿墙**：沿后退方向按最近可用距离回缩（最短 0.3 m），近墙时玩家模型改半透明；绝不自动改写视角状态位，保证 HUD 指示与相机一致。
6. **同帧多次命中 / HP 归零**：一帧内先累计伤害再统一判定，HP 下限 0；死亡立即冻结输入与波次生成。
7. **极端 dt**：dt 上限 0.05 s；射速/换弹/Bot 开火/波间均按累计 dt 计时，不按帧计数，保证高刷设备一致。

## 10. 自检与 T2 实现约束
- **红线自检**：切镜无数值收益（FOV 固定、射线共用）+ Shift 减速代价 → 无主导策略；备弹 ∞ 但弹匣 8 发、第 3 波必换弹 → 换弹有意义且无资源囤积；HUD 仅 6 块、单武器单地图 → 无认知过载；愿景项隔离 → 无支柱漂移。
- **硬约束**：① 命中为 hitscan 即时射线，无飞行弹丸（勿实现投射物）；② 场景为不相交轴对齐 AABB，画家算法按面中心到相机距离降序绘制，**必须实现近裁剪面 0.1 m**，否则穿墙时投影发散；③ 玩家 / Bot y 恒定；④ 切镜只改相机位置与模型显隐，共用 yaw/pitch 与射线，FOV 75° 固定；⑤ 所有计时用累计 dt（上限 0.05 s）；⑥ 零外部依赖、零贴图；⑦ 移动端性能兜底：可降渲染分辨率后 CSS 放大；⑧ `config/games.json` 注册第 11 项属 `cs/` 之外的全局文件，与「禁止改动 cs/ 以外文件」冲突，须由主理人向用户确认后处理。

## 11. v2 扩展（跳/蹲/枪械/渲染升级）
> 本节追加于 v1 概念卡之上，冲突处以本节为准。本轮仍不做：爆头、手雷、武器切换、联网、外部贴图、WebGL；「明确不做」中放开：蹲伏、跳跃。

### 11.1 跳/蹲数值基线（单位已标注）
| 参数 | 值 | 单位 | 说明 |
|---|---|---|---|
| 跳跃初速 | 4.5 | m/s | 蹲跳 ×0.85 = 3.8 m/s |
| 重力 | 12 | m/s² | 游戏化数值，手感折中 |
| 跳跃高度 | 0.84 / 0.60 | m | = v²/2g；跳 / 蹲跳 |
| 滞空时间 | 0.75 / 0.63 | s | = 2v/g；跳 / 蹲跳 |
| 空中水平加速度 | 3.6 | m/s² | 取地面等效 12 m/s²（0→4.0 m/s 需 0.33 s）的 30%；地面维持 v1 直接置速不变 |
| 空中散布 | ±12 | 度 | 起跳即生效；Shift 在空中无效 |
| 落地散布 | ±10 → 0 | 度 | 落地瞬间起 0.30 s 线性衰减回常规模型（静止 0 / 蹲移 1 / 步行 3） |
| 蹲触发 | Ctrl / C 按住 | — | 非切换式；C 为别名键 |
| 蹲眼位 | 1.60 → 1.05 | m | 平滑过渡 0.15 s，蹲起对称；过渡期反向输入排队防抖 |
| 蹲移速 | 2.0 | m/s | 蹲静止沿用站立静止散布逻辑 |
| 蹲散布 | 静止 0 / 移动 ±1.0 / 蹲起过渡 +1.0 | 度 | 取移动 ±1.0 而非 0.5：0.5° 在 18 m 偏差 ≤0.16 m < Bot 公告板半宽 0.4 m，等效 0°，将支配 Shift（见下算账③） |
| 跳中换弹 | 允许，计时继续 | — | 换弹=资源管理动词，与切镜不中断计时同理；空中散布使开火无收益，不构成空中输出策略 |
| 碰撞不变 | 圆 r=0.4 | m | 跳/蹲不改 x/z 碰撞、不支持站上 AABB 顶面（列愿景）；与 Bot 碰撞推挤照旧 |

**无主导策略算账**：① 空中输出 tan12°≈0.213 → 10 m 处横向偏差 ±2.1 m ≫ 命中半径 0.4 m，期望命中率 <0.2 → 空中 DPS <1 发/s 对比站定 5 发/s，跳纯亏；跳不翻越掩体、不加速位移 → 无收益即无主导。② 连跳：落地 ±10° 惩罚 + 水平速度不保留增益 → 零收益。③ 蹲移 2.0 m/s/±1.0°、Shift 1.8 m/s/0°、步行 4.0 m/s/±3° 为速度-精度前沿三个互不支配点；蹲无规避收益（11.2）、蹲起过渡 +1.0° 惩罚、转场最慢 → 无主导。

### 11.2 Bot 对跳/蹲的处理
Bot 不跳、不蹲（状态机零新增状态）。**玩家跳/蹲不调整 Bot 命中率**（维持 0.35/0.45/0.55）：跳跃代价由 ±12° 空中散布承担；蹲不提供规避收益（Bot 命中为概率 roll，与姿态无关），蹲的价值只在玩家侧散布档位。Bot 视线判定仍为 2D 墙体遮挡——蹲不躲视线、跳不越视线。修正表：无新增条目。

### 11.3 枪械视图模型（屏幕空间 2D，不占 3D 面池）
FPS 右下几何枪：5 个多边形色块（枪身/枪管/握把/准星座/弹匣），锚点 (0.72W, 0.85H)，随主题取色（沿 ADR-4）。
| 动画 | 数值 |
|---|---|
| 移动 sway | 幅度 ±6 px ×（速度/4.0 m/s），频率 1.6 Hz |
| 转视角 lag | 60 ms 延迟反向偏移，上限 10 px，指数回弹 τ=0.15 s |
| 开火后坐（枪） | 上移 12 px + 后缩 4 px，τ=0.10 s 指数回落 |
| 开火后坐（视角） | pitch 真实上踢 +1.2°（进射线方向，可下拉补偿），0.15 s 自动回落；射速间隔 0.20 s > 0.15 s → 连发每发从基准 pitch 出膛，代价轻微但真实 |
| 换弹动画 | 下移 40 px + 下旋 25°：0.25 s 出 / 0.90 s 保持 / 0.25 s 回，总长 1.4 s 与换弹计时锁定 |
| 枪口火光 | 0.04 s（≈2 帧），枪口锚点 2-3 个星形面片，主题亮色 |
TPS：玩家公告板旁追加 1 面竖条枪（3D 面池 +1），随玩家面显隐。

### 11.4 渲染升级范围
| 项 | 规格 |
|---|---|
| 程序化纹理 | 砖墙/混凝土/木箱/地面 4 种，64×64 px 离屏 canvas，init 时一次生成（×2 主题 = 8 张缓存），themeChanged 仅换引用；运行时零生成零加载 |
| 伪光照 | shade = 0.55 + 0.45×max(0, n·L)，L=normalize(0.4, 0.7, 0.6) 固定太阳方向；面朝向 6 档预计算；绘制后同路径叠黑 alpha=1−shade |
| 天空渐变 | 屏幕空间线性渐变（顶深→底浅），gradient 对象 init 缓存，逐帧零分配 |
| 距离雾 | f = clamp((d−10)/40, 0, 1)²，d=面中心距（m）；10 m 内无雾、50 m 全雾（<60 m 远裁剪）；面绘制后同路径填雾色 alpha=f |

### 11.6 性能预算修订
- 体积：cs/ 内 html+css+js 上限 100 → **150 KB**。
- 逐帧 3D 面算账：墙 12×3=36 + Bot 5×2=10 + TPS 玩家 2+枪 1=3 → 最坏 49 面；**面池上限 80 维持不变**（余量 31）。弹孔/粒子/弹壳/火光/视图模型全部屏幕空间或墙面附属绘制，面池零占用。
- 绘制调用预算：纹理墙 36 drawImage + Bot 10 + 玩家 3 + 弹孔 ≤32 + 粒子 ≤64 + 弹壳 ≤8 + 枪械 ≤8 path + 火光 ≤3 + 天空 1 ≈ ≤165 次/帧，Canvas 2D@60fps 可承受；移动端维持 ×0.8 分辨率兜底，实测 <45 fps 自动切 `Renderer2DFlat` 纯色块降级。
- 逐帧零分配红线不变：粒子 64 / 弹壳 8 / 弹孔 32 / 火光 1 均预分配池；纹理与渐变对象仅 init 与 themeChanged 时生成。

### 11.7 操作映射新增
| 输入 | 功能 |
|---|---|
| Space | 跳（落地即可再跳；连跳无收益见 11.1 算账②） |

### 11.8 边缘情况追加（接第 9 节编号）
1. **跳跃中开火/换弹**：均允许、计时继续；空中散布 ±12° 生效，换弹不被落地中断。
2. **蹲下瞬间被击中**：Bot roll 与姿态无关，伤害照常结算；眼位平滑不影响已发射射线。
3. **空中切镜**：仅改相机；TPS 下玩家模型 y 跟随跳跃；射线仍从实际眼位（含跳跃高度）发出。
4. **跳向 Bot / 墙体**：跳跃不改 x/z 碰撞 → 不可能入墙；与 Bot 圆碰撞推挤照旧；不支持站上 AABB 顶面。
5. **空中失焦暂停恢复**：停帧冻结 dt，恢复后按冻结前空中状态（速度/散布/换弹进度）继续，不补算。
6. **落地散布窗口开火**：落地 0.30 s 内开火受 ±10°→0 衰减散布，准星间隙实时反映。
7. **Ctrl 快捷键冲突**：可拦截键一律 preventDefault；Ctrl+W 不可拦截，操作说明标注推荐 C 键。
8. **蹲起连按抖动**：0.15 s 过渡期间反向输入排队，过渡结束才执行，眼位不抖。

### 11.9 红线自检
- **切镜零收益仍成立**：射线仍固定玩家实际眼位 (x, eyeY, z)+yaw/pitch，eyeY 随蹲/跳变化但与相机位完全解耦；切镜仅改相机位与模型显隐，数值逐位一致。
- **零依赖仍成立**：纹理程序化生成、音效 cs/ 内合成、渲染器为自有接口，无新库、无外部资源、无 WebGL。
- **无主导策略**：跳=纯亏手感动作（11.1 算账①②）；蹲=速度-精度前沿非支配点且无规避收益（③）；视图模型/特效/音效=纯表现零数值；面数 49<80、体积 <150 KB、逐帧零分配 → 三支柱均未漂移。
